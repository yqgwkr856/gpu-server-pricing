## 决定 GPU 服务器价格的，其实就那么几件事

显卡型号是第一变量，但不是唯一变量。同一家云厂商内部，价差往往来自三个地方：

- **整卡还是切片**。独享整张卡和跟别人共用一张卡的切片，成本结构完全不同。
- **显存和配套资源**。CPU 核数、内存、硬盘类型、带宽、防御，都会叠加进最终报价。
- **计费方式**。按小时、包月长租、固定月费加开机时长，三种模式算下来的实际支出可以差好几倍。

拿阿里云公开的实例报价做参照就很容易看明白：`gn8v-8x.16xlarge`（64 vCPU / 768 GiB，8 卡整机）按量 277.22 元/小时，包月 133065.94 元；而 GPU 共享型 `sgn6i-vws-m2.xlarge`（4 vCPU / 10 GiB）只要 1.68 元/小时、807.05 元/月。两边都是"GPU 实例"，差距不在品牌，在于前者是整机多卡独占，后者是把算力切碎了卖。

如果你的任务只是跑个推理、挂个机、出几张图，盯着后一档就够了。

## 三种计费方式，直接决定你每月实付多少

**按量计费**：按秒或按小时结算，开多久算多久。适合跑一次训练、临时渲染、压测这类几天内结束的活。单价最高，但总量可控。

**包月长租**：一次性买断一个月，随便开机。适合长期挂机、常驻服务、云游戏这类几乎不关机的场景，折算到每小时通常最便宜。

**固定月费 + 开机时长**：这是很多人忽略的一种。月费很低，开机时按小时加收，关机不额外计费，开通时还送几个小时。间歇性使用最划算，一个月只玩几次的人，比长租省得多。

雨云的显卡云就是按后两种模式并行的。以广东深圳的 V100 机型为例，"日常网吧型"固定 28 元/月，开机加收 2.5 元/小时，关机不计费，每月还赠送 5 小时；"算力长租型"638 元/月起，没有时长限制。广东广州的 RTX3080 机型同规则，固定 29 元/月，加时同样 2.5 元/小时。

一个月用不到 20 小时的人，选前者；准备 7×24 挂着，选后者。

## 百元档的 vGPU 显卡云，现在能买到什么

vGPU 的做法是把 Tesla P40、V100、RTX3080 这类卡的算力按显存切分，一台机器分你 1G 到 16G 显存。单价能压到几十元一个月，代价是显存和算力有上限，且部分机型是 NAT 共享公网 IP。

这一档覆盖的场景比想象中多：AI 绘画出图、小参数模型推理、SillyTavern 之类的对话应用、游戏挂机、云游戏串流、轻量 3D 渲染、远程办公。以宁波的 P40 机型为例，系统可选 Ubuntu 22.04 或 Windows Server 2022，出厂已装好 NVIDIA 驱动（Driver 版本 535.129.03），CUDA 直接可用，不用自己折腾环境。

对只是想跑通一个模型、验证一个想法的人来说，这个价位段的试错成本很低。

## 常见问题

**显存到底该选多大？** 1–2 GB 只能跑极轻量的推理和挂机；4 GB 是跑 Stable Diffusion 出图、小模型的舒适线；8 GB 以上才能装下参数量更大的模型。很多 AI 项目的最低门槛就是 8 GB，这也是 P40 旗舰档存在的原因。

**能不能装 Windows？** 可以。宁波 P40 机型支持 Ubuntu 22.04 Server LTS 和 Windows Server 2022 数据中心版，出厂预装 NVIDIA 驱动，不需要自己装显卡驱动。

**按时计费型和长租型怎么选？** 算一下你每月大概开多少小时。按 2.5 元/小时算，超过 200 小时基本就接近长租的固定月费了，到这个量级就该买长租型。

**便宜是不是意味着不靠谱？** 便宜主要来自老架构专业卡和 vGPU 切分，不是虚标。雨云成立于 2018 年，持有 ISP、IDC、CDN 相关经营许可，GPU 以 vGPU 形式分配这一点在官方说明里写得很清楚——知道自己买的是切片而不是整卡，预期就不会错。
